# SQL 문제 풀이 포트폴리오

> 복잡한 SQL 문제를 **논리적으로 분해**하고, **재구성하는 과정**을 기록하는 학습 포트폴리오

---

## 📌 프로젝트 목표

- SQL 문제를 풀 때의 **사고 과정** 문서화
- "**왜 이렇게 했는가**"를 보여주기
- 데이터 분석 문제 해결 능력 개발

---

## 🎯 학습 원칙 (Chris Piech 교수님의 철학)

> "문제를 먼저 충분히 이해하고, 그 다음 코드를 짜라."

### 5단계 문제 해결 방법론

1. **문제를 손으로 그려보기** — 표 이미지화
2. **필요한 요소 나열하기** — 최종 결과에 필요한 정보 파악
3. **각 요소의 출처 파악** — 어느 테이블에 있나?
4. **연결 고리 찾기** — 외래키로 테이블 연결
5. **마지막에 코드 작성** — 위 4단계 후 쿼리 작성

## 🚀 시작하기

각 문제를 학습할 때:

1. **Notion 문서** 읽기 — 5단계 풀이 과정 따라가기
